# Changelog

## 1.0.0 — 2026-09-25

First public release.

- Project-aware feature ideation with 5–10 distinct proposals and seven by default.
- Required illustration per feature, with visual inspection and an honest incomplete-output fallback.
- Prioritization, MVP implementation plans, acceptance tests, failure cases, and proposed success metrics.
- Three fictional worked examples spanning apps, APIs, and command-line tools, with 15 illustrations.
- MIT license, contribution guidance, issue templates, and automated repository validation.
- Lightweight installable package containing the skill, invocation metadata, and license.

Examples demonstrate the intended output. They are not evidence of production deployments or a model benchmark.
