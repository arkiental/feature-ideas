# Feature Ideas 1.0.0

The first public release of an agent skill for illustrated feature brainstorming and MVP planning.

## Included

- An installable `feature-ideas` skill with Codex invocation metadata.
- Five to ten project-specific proposals per run, each with a required illustration.
- Prioritization, MVP steps, acceptance tests, edge cases, and proposed metrics.
- Three fictional worked examples and 15 illustrations across apps, APIs, and CLI tools.
- MIT licensing and contribution guidance, including issue and pull request templates.
- Repository validation and a deterministic lightweight skill ZIP.

## Installation

Ask `$skill-installer` to install from:

`https://github.com/arkiental/feature-ideas/tree/v1.0.0/skills/feature-ideas`

Or extract `feature-ideas-1.0.0.zip` into your host's skill directory. It contains a top-level `feature-ideas/` folder. See the repository README for host requirements.

## Limitations

Output quality depends on the model, project context, and visual tools. The skill cannot create images through a text-only host. The examples are conceptual documentation, not shipped products, automated benchmark results, or executed feature tests. Other agent hosts have not been end-to-end tested.
