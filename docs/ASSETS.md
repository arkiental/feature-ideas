# Illustration provenance and reuse

All example projects, task names, events, and terminal data in this repository are fictional. No customer screenshots or third-party product UI assets are included.

## Daymark app concepts

The five PNGs in `examples/task-planner/images/` were generated with the built-in OpenAI image-generation tool on 2026-09-25, using the feature brief and original prompts in [image-prompts.json](../examples/task-planner/image-prompts.json). Targeted edits corrected the distinction between scheduling and completion, clarified dependency-arrow labels, and removed unnecessary promotional copy.

The prompts are reproducible inputs, not a guarantee of pixel-identical regeneration. Tool availability and output may change. These illustrations were inspected as images; they are not functional prototypes. Text descriptions alongside them define the intended behavior.

## Relaybox and Tablecraft diagrams

The ten SVGs are original, editable diagrams authored for these fictional briefs. Matching PNGs are rendered exports. Each example includes generator sources and regeneration instructions. SVG generation is deterministic and does not need a paid image service. PNG export uses Sharp; fonts can affect rendering across machines.
